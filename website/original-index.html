Pointer Arithmetic & Dynamic Memory (malloc/free)

High-yield revision note • By Rahul Sharma (Mentor) • 8 min read

Exam Verified
int *arr = (int *)malloc(5 * sizeof(int));
// *(arr + i) is syntactically equivalent to arr[i]

Key Formula / Principle: Pointer arithmetic scales automatically by sizeof(T). Incrementing an int* by 1 increases the actual physical memory byte address by 4 on 32/64-bit architectures.

📌 Trap to Avoid
Dangling pointers: always set ptr = NULL; immediately after calling free(ptr);
⚡ Exam High Yield
Memory leaks occur on the heap when dynamically allocated blocks lose their pointer reference.
